# X / Twitter Rules

## Length
- Singles: well under 280, aim ~200
- Threads only for genuine build-logs

## Hashtags
- None.

## Formatting
- Line breaks fine, especially for punchlines
- Quote-tweets: one sharp line + link

## Mode mix
- Build-in-public: "Set up the OpenArm today. First pick task failed exactly how the pi paper predicted."
- Hot take: "pi 0.7 is doing [specific thing], first time I've seen [specific outcome]."
- Nerd humor: dry observation, not a punchline. "Every VLA demo video is shot in the same kitchen."
- Dense technical: rare, must earn it. Include the specific parameter, metric, graph.

## Avoid
- Hashtag spam
- Threads with filler
- Thirst posting
- Self-congratulation
